# Frontend

React, TS, Tailwind, RTK Query

## Запуск

```bash
npm install
npm run dev
```

```bash
npm run build      # tsc + vite build → dist/
npm run preview    # локально посмотреть собранное
```


## Скрипты

- `npm run dev` - dev запуск
- `npm run build` - билд статики
- `npm run format` - форматирование всего проекта
- `npm run format:check` - проверка форматирования для CI
